### 📁 Featured Applications

- 🎥 **[RP16 Coach – Real Time AI Interview Coach & Multi-Modal Emotion Tracker](https://github.com/Rohanmpatil16/Interview-Coach-Emotion-Tracker)**  
  Engineered a real-time, multi-modal AI interview coaching platform using Java, Spring Boot, Spring AI, OpenCV, and React. Implemented low-latency full-duplex WebSockets streaming 1 FPS video snapshots and 16kHz audio buffers for gaze, emotion, and pitch analysis with automated transcript cleanup and an OpenCV face-presence gate.

- 💳 **[Offline UPI Mesh – Deferred Settlement Engine & Bluetooth Mesh Simulator](https://github.com/Rohanmpatil16/Offline-UPI-Mesh)**  
  Architected a Spring Boot backend and mesh simulator for offline UPI payments with deferred server settlement using Java 17, Spring Data JPA, MySQL, and JUnit 5. Features an Atomic Idempotency Engine (SHA-256 ciphertext hashing) and zero-trust hybrid RSA-OAEP + AES-256-GCM encryption with TTL-decremented gossip propagation.

- 📊 **Data Science & AI Pipeline Projects** *(RacksonsIT Developers)*  
  Developed data analytics and machine learning tools utilizing Python, pandas, REST APIs, and Power BI for data preprocessing, statistical modeling, and interactive visualization dashboards.
